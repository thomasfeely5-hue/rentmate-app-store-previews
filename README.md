# rentmate-app-store-previews

Public RentMate App Store screenshots based on genuine iPhone captures of the
submitted V1 build.

The current five-image set presents Home, Expenses, Spending, Messages and
Rental Passport/RentMate Score in a feature-led order. Personal names, contact
details, street addresses, household invite codes and private message content
were replaced with clearly synthetic demonstration data. Unsuitable expense
labels were replaced with ordinary household expenses.

Every screenshot is a 1242 x 2688, 24-bit RGB PNG with metadata stripped. The
source status bars were removed rather than simulated, and the set excludes the
future-version Rewards screen so the listing represents only current V1
features.
